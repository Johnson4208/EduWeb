# Little Lingua — Children's Language Learning App

A responsive front-end starter project for a playful language-learning experience for children. Built with plain HTML, CSS, and JavaScript so it is easy to open, understand, and customize.

## Run it

1. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
2. Open `index.html` in a modern browser. No build step or server is required.
3. For the best pronunciation support, use a browser with Web Speech API voices installed. The available voices depend on the device and browser.

## Included

- Dashboard with a daily goal, learning paths, a word of the day, and a weekly activity view.
- Vocabulary cards with Spanish, French, and Japanese translations.
- Pronunciation through the browser's built-in speech synthesis when available.
- A simple picture-to-word matching game.
- A three-page mini story.
- Progress stats stored in the browser's local storage on the current device.
- Responsive layouts for desktop, tablet, and mobile.
- Grown-up settings for nickname and daily goal; clearly marked as a demo rather than a parental lock.

## Notes before production use

This is a polished front-end prototype, not a complete commercial learning platform. Translation lists and story content are sample content and should be reviewed by fluent speakers and child-learning specialists before release. It has no backend, accounts, parental consent flow, synced progress, or production-grade child-safety controls. Progress is stored locally and can be reset from **My progress**.
